GitHub 파일 열기와 공유하기

GitHub에 올린 HTML 발표 자료를 실행하거나, 저장소의 Markdown 문서를 문서 형태로 읽을 때 사용합니다.

  1. GitHub에서 공개 저장소의 파일을 엽니다. 주소에 /blob/이 있고 파일명이 .html, .htm 또는 .md로 끝나는지 확인합니다.
  2. 파일 주소를 복사해 HTML & Markdown Viewer에 붙여넣고 열기를 누릅니다.
  3. 왼쪽 위 공유 버튼으로 링크를 복사합니다. 입력 화면으로 돌아가려면 홈 버튼이나 Esc를 사용하세요.

파일 유형에 따른 동작

Markdown 파일은 GitHub의 원본 파일 서버에서 읽어 문서로 표시합니다. 예를 들어 뷰어 저장소의 README.md 주소를 붙여넣어 볼 수 있습니다. HTML은 Raw Githack 주소를 만들어 별도 프레임에서 엽니다. 출처를 신뢰할 수 있는 HTML만 여세요.

파일이 열리지 않을 때

저장소 첫 화면이나 폴더 주소 대신 파일 주소를 사용하세요. 파일이 이동했거나 비공개 상태라면 다른 사람도 공유 링크에서 열 수 없습니다. 문제가 생기면 먼저 원본 파일을 로그아웃 상태에서 열 수 있는지 확인하세요.

공유 링크에는 원본 파일 주소가 들어갑니다. 최근 열어 본 주소는 현재 브라우저에 남으며, 입력 화면의 전체 삭제로 지울 수 있습니다.
