Markdown을 일반 텍스트로 복사하기

회의 메모를 메시지에 옮길 때 제목의 ##이나 강조에 쓰인 **가 보이면 Remove Markdown으로 정리할 수 있습니다.

  1. Remove Markdown의 입력창에 원문을 붙여넣습니다.
  2. 결과창에 바로 나타나는 텍스트를 확인합니다. 원문 없이 시험하려면 예시를 누릅니다.
  3. 복사를 눌러 메모 앱이나 메시지에 붙여넣습니다.

변환 전후

입력

## 화요일 회의
* **초안** 검토
- [ ] [일정](https://example.com/schedule) 확인

결과

화요일 회의
- 초안 검토
- [ ] 일정 (https://example.com/schedule) 확인

목록의 들여쓰기, 번호, 체크박스는 남습니다. 링크는 설명 뒤에 주소가 붙고, 코드 블록은 코드 내용을 보존합니다. 언어가 지정된 코드 블록에는 [swift] 같은 표시가 붙습니다.

표와 복잡한 문서

표는 결과창에서 표로 보입니다. 복사 버튼은 HTML과 평문을 함께 제공하므로 붙여넣는 앱이 HTML을 받으면 표를 유지할 수 있습니다. 평문으로 붙여넣으면 열 사이가 탭으로 구분됩니다.

참조형 링크, 복잡하게 중첩된 링크, HTML 기반 서식은 변환 대상에서 벗어날 수 있습니다. 긴 문서는 붙여넣기 전에 링크와 표가 의도대로 남았는지 확인하세요.
